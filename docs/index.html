让验证码自动填充。

OTPilot 是一个 macOS 菜单栏小工具。它读取本机 Messages 里的新短信验证码，复制到剪贴板，并可选择粘贴到光标所在的输入框，给 Dia、Chrome、Arc 带来接近 Safari 的体验。

下载 DMG 查看 GitHub
本机处理 直接读取 Mac 上的 Messages 数据库，不经过云端服务。
中英模板 支持常见英文、简体中文和繁体中文验证码格式。
菜单栏常驻 没有 Dock 图标，打开后默认开始监测新消息。

只做核心功能，因此足够可靠。

OTPilot 不尝试接管浏览器，也不在网页里注入脚本。它只在新消息到达时判断验证码，剩下交给 macOS 剪贴板和当前应用自己处理。

1

监测 Messages

应用启动后从最新消息开始读取，只处理之后进入 `~/Library/Messages/chat.db` 的 SMS / iMessage 记录。

2

提取验证码

解析器先找验证码关键词，再枚举附近 4-8 位候选，过滤 URL、日期和时间，选出最有可能是验证码的那条。

3

复制，或粘贴

检测成功后自动复制到剪贴板。若开启 Auto paste 且当前焦点是可编辑输入框，它会发送 Command-V。

权限保持透明。

这是一个本机工具，所以权限边界应该清楚。OTPilot 代码开源可审查，核心流程留在本机，不上传短信内容，也不会在没有输入焦点时盲目粘贴。

完全磁盘访问权限

用于读取本机 Messages 数据库。这是 macOS 隐私系统对 `chat.db` 的要求。

辅助功能

只有在启用 Auto paste 时需要，用来确认当前焦点是否可编辑，并发送 Command-V。

通知

可选。只在验证码已复制但没有自动粘贴时提示，不展示验证码本身或发件人。

Open source

代码可以直接审查。当前应用没有网络同步或分析逻辑；短信解析、复制和粘贴都在本机完成。

下载 DMG，拖进「应用程序」。

OTPilot 现在提供预构建 DMG，普通用户不需要 Xcode。使用前请确认 iPhone 已为这台 Mac 打开「短信转发」，或已经同步 iMessage。

给普通用户

在最新发布页下载 `OTPilot-v1.7.0.dmg`，打开后把 `OTPilot.app` 拖进「应用程序」。Apple Silicon 和 Intel Mac 都支持。
